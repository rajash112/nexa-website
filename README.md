# NEXA – Next-Gen Education & Expertise Academy (website)

Static site generated by a small Node build script. Output goes to `dist/` and is deployed on Netlify.

## Quick start
```bash
npm install
npm run build        # builds dist/
npm test             # build + link check + claims/privacy lint + content-parity
node scripts/serve.mjs   # serve dist/ at http://localhost:8080
python3 tests/e2e.py     # browser tests (needs Playwright + Chromium)
python3 tests/a11y.py    # accessibility scan (axe-core)
```

## Structure
- `src/data/` – course curricula (`courses-a.js`, `courses-b.js`), official syllabus records (`institutions.js`), contact details (`site.js`)
- `scripts/build.mjs` – generates every page, the 19 PDFs, sitemap, robots.txt
- `src/css`, `src/js`, `src/assets` – styles, scripts, self-hosted fonts, images
- `gallery-candidates/` – the 20 processed, approved session photos + `manifest.json` (copied into the site at build time; see `docs/PHOTOS.md`)
- `tests/` – browser tests, parity baseline; `docs/` – deployment, forms, photos, testing report, feature list

## Rules this project enforces
No invented testimonials, student counts, partnerships, ratings or placements (`scripts/lint-claims.mjs`). Official university syllabi stay clearly separated from NEXA-authored curricula. Published photos carry no metadata. Existing content and URLs are protected by `scripts/content-parity.mjs` against the production baseline.
